# QuickShop E-Commerce Web API

A production-ready microservice web API and database infrastructure setup for QuickShop.

## Architecture Overview
* **Application:** .NET 8 Web API
* **Infrastructure:** Azure Bicep (App Service & SQL Database)
* **CI/CD:** GitHub Actions

## Getting Started Locally

### Prerequisites
* .NET 8.0 SDK installed
* Azure CLI installed
